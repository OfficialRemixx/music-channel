Privacy Policy

Last updated: 2026-10-14

This policy covers the "Deep Focus" YouTube channel and the automated pipeline (the "Service") that generates and publishes its videos. The Service is operated by a single individual (the "Operator") for their own YouTube channel. Its source code is public: github.com/OfficialRemixx/music-channel.

What the Service does

The Service automatically generates original, instrumental background-music videos (for focus/study/ambient use) using an open-source AI music model, and uploads them to the Operator's own YouTube channel through the YouTube Data API. Every video the Service uploads is marked as containing synthetic ("AI-generated") media, per YouTube's content disclosure requirements.

Whose data this covers

The Service does not operate on behalf of, or collect data from, anyone other than the Operator. It has no sign-up flow, no user accounts, no comment system, and no analytics tracking of channel viewers beyond what YouTube itself already provides to any channel owner through YouTube Analytics. If you are watching a "Deep Focus" video, your use of YouTube is covered by Google's Privacy Policy, not by this one.

Google user data accessed by the Service

The Service uses Google OAuth to access the Operator's own YouTube channel, under the youtube.upload and youtube.readonly scopes, solely to:

  • Upload videos the Service generates to the Operator's channel;
  • Read back the status of those uploads (processing status, content ID claims, rejection reasons) to confirm each upload succeeded cleanly before it is ever made public;
  • Look up YouTube's public video category list so uploads are tagged correctly.

No data read from the Operator's YouTube account is shared with any third party, sold, or used for advertising. The Service's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other services the Service talks to

None of the following receive any personal data about anyone other than the Operator's own API credentials, which the Operator controls directly:

  • Kaggle -- runs the AI music-generation model on a GPU notebook under the Operator's own Kaggle account.
  • Pixabay -- supplies royalty-free cover images for the videos, under the Pixabay Content License.
  • A private Telegram bot -- sends the Operator status notifications about the pipeline's own runs (e.g. "upload succeeded"). No viewer or channel-audience data is ever sent here.

Data retention

The pipeline's working state (which tracks have been generated, which videos have been uploaded) is stored in the Service's own public GitHub repository, not in any database of personal information, since none is collected.

Contact

Questions about this policy can be raised as an issue on the GitHub repository.
